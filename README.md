# Starrcraft
Minecraft-clone in 2D style in Java

HOW TO USE AND RUN:

Clone the repository with the command "git clone https://github.com/godblessed-srth/Starrcraft.git" and navigate to the project folder (Starrcraft). 
hen compile the files with the command javac *.java (if not Java, install the openjdk-21-jdk package on Linux; install Java on Windows). 
The project is created as a portfolio or template for someone else's project, which can be used for free.
